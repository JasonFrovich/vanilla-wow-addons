# 01 Scope — ICM Layer 2

## Inputs
Owner request; current repo/branch/source SHA; AGENTS.md; any existing task or owner decision.

## Process
1. Identify task ID, falsifiable question, affected paths, intended result and prohibited operations.
2. Check prior verified work and define minimal relevant source/test selection.
3. Pin exact commit, fixture ID, owner and approval boundary.

## Outputs
Private 01-scope/scope.md with source pins, scope, known unknowns and next stage.

## Check
Stop if task identity, source SHA, authority or scope is ambiguous. No live operation is authorized.
