# 04 Report — ICM Layer 2

## Inputs
Valid current scope, evidence and verification records plus actual reviewer/owner decisions.

## Process
1. Revalidate source and predecessor digests; distinguish direct observations from assumptions.
2. Summarize changes, tests (including NOT RUN), uncertainties and unmodified assets.
3. Provide one bounded safe next action, owner gate and complete read-only reviewer prompt if a substantial PR is review-ready.

## Outputs
Private 04-report/report.md; only deliberate sanitized reports can enter GitHub.

## Check
A fresh session must recover task ID, source SHA, evidence provenance, verification and next safe action without chat memory. Do not claim review, merge or deployment without proof.
