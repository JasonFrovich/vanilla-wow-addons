# 02 Evidence — ICM Layer 2

## Inputs
Valid 01-scope evidence with matching source pins; actual source/tests and observed logs.

## Process
1. Check predecessor identity/digest and inspect only relevant Layer 3 files.
2. Label OBSERVED, USER-REPORTED, INFERRED, UNKNOWN and DISPUTED assertions.
3. Record source paths/lines, fixture or observation time, contradictions, privacy class and test hypothesis.

## Outputs
Private 02-evidence/evidence.md with cited observations, predecessor digest and gaps.

## Check
Do not claim source observations from memory or stale SHAs; stop on missing or changed predecessor.
