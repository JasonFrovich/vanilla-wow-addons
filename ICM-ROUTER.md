# Vanilla WoW Addons — ICM Layer 0 router

Read AGENTS.md first.

| Task | Route | Permission |
| --- | --- | --- |
| Substantive, safety-sensitive, multi-file or cross-session change | workspaces/engineering/CONTEXT.md | Private task-scoped Scope → Evidence → Verify → Report |
| Small standalone fix | AGENTS.md plus the relevant real source/test | Direct engineering; no staged paperwork |
| Resume an earlier investigation | Its exact private handoff + docs/ICM_CORE_ADOPTION_STANDARD.md | Verify task, source SHA, predecessor digests; never silently recreate |
| Merge, install, privileged access, cloud change, deletion or schedules | Existing project owner/release controls | ICM does not grant operational authority |

Layers: L0 this router and AGENTS; L1 workspace CONTEXT; L2 one stage CONTEXT at a time; L3 authoritative repository policies/source; L4 private, per-task outputs. Library memories and other chats are not automatically loaded.
